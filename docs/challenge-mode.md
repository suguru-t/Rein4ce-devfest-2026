# 3分チャレンジ（Issue #45、B案のドラフト）

「積む」の中で「通常」と「3分チャレンジ」を選ぶ。通常の最大5個のゲーム、採集したパーツ、ギャラリー、サーバには変更を加えない。

- 固定の5形状（棒・L・U・輪・ジグザグ）。長辺1m・通常の摩擦。丸い描画・角ばった当たり判定は共通の `StackWorld` を使う（#67・#71）。
- 各5問に全種類が1回ずつ出るシャッフルバッグ。`java.util.Random` の種とルール `manual-180-v1` を記録し、同じ種なら同じ順で再現する。形・摩擦・時間のルールを変えたらIDも変える。
- 手動で左右移動（0.1m）・回転（15度）し「置く」。自動落下するA案は含まない。
- 180秒の前景経過時間。単調時計を使い、物理の時間上限とは分離する。背景・別タブ・通常モードへ移った間は時計と物理を止める。画面回転ではViewModelが保持する。OSによるプロセス終了時の途中再開は対象外（確定済みの記録は残る）。
- 入力時にも時計を更新し、締切ちょうど以降の移動・回転・配置を拒否する。締切直前に置いたピースは対象、置く前のゴーストは対象外。
- 各配置後と締切後、落下したものを毎フレーム除去し、静止を待つ。0.8秒以降に全て静止したら次へ進む。物理時間6秒でも静止しなければ未確定として終了し、浮いている塔をランキングに登録しない（#41の意図）。締切後に静止した高さだけを固定する。
- 結果は端末内の専用JSONにAtomicFileで保存。run IDで重複を防ぎ、同じルールだけを高さ順に並べる。同値は同順位。書き込み失敗は表示して再試行でき、保存が済むまで次のゲームを始めない。破損したデータを空として上書きしない。

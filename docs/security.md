# セキュリティとプライバシー

発表で「セキュリティは？」「位置情報は大丈夫？」と聞かれたときに答えられるよう、このアプリがしている対策と、していないこと（と理由）を 1 枚にまとめる。
決めた経緯は `docs/decisions.md`（とくに 4・8・9・21・23・32・47）。

## 1. 歩いた場所を外に出さない

位置情報は、このアプリでいちばん大事に扱うもの。**歩いた場所（緯度・経度）は、スマホの外に出さない。**

- **サーバに送るのは道の「形」だけ**：向きと大きさをそろえて、24 点までに間引いた線と、距離・歩いた日付。緯度・経度は送らない（`core/model/Part`）
- **歩いた場所はスマホの中だけ**：拡大表示の地図に使う場所は、アプリ専用の領域に保存する（`parts_places.json`）。クラウド（Google ドライブ）のバックアップには入れない（`allowBackup="false"`）。機種変更で新しいスマホへデータを移すとき（端末から端末への移行）は、自分のスマホどうしなので止めていない（Android 12 以降は、`allowBackup="false"` でも移る）
- **公開するタワーの時刻は日付まで**：送ったタワーは誰でも読めるので、何時何分に歩いたか（ふだん家を出る時刻など）が分からないよう、パーツを歩いた時刻と、タワーを作った時刻（歩いてすぐ積んで送ると、ここから歩いた時刻が分かる）を、日付までに丸めて送る（`net/ApiClient` の `withDayOnlyTimes`）。「みんな」の画面にも日付だけを出す
- **天気を聞くときは位置をぼかす**：0.1 度（約 10 km）に丸めてから Open-Meteo に送る（`core/weather` の `OpenMeteo.round`）
- **AI に送るものも最小限**：パーツの名前を考えてもらうときは、形・距離・日時だけ（自分で付けた名前も送らない）。ニックネームは、パーツの名前・本数・合計距離だけ。設定の「AI に名前を考えてもらう」をオフにすれば、何も送らない
- **位置の許可は使っている間だけ**：「常に許可」（バックグラウンドの位置情報）は求めない。記録は、アプリを開いてボタンを押したときだけ始め、記録中は通知を出す。記録していない間も、記録画面を開いている間だけ今いる場所を聞いて、地図に青い点を出す（保存も送信もしない。裏に回ったり、ほかのタブに移ったりしたら止める。#91）

## 2. ログインなしで「自分のタワー」を見分ける

- 端末ごとの印は、端末の ID（`ANDROID_ID`）に**アプリだけの塩を付けて SHA-256** にした 64 桁。元の ID は送らない（`data/OwnerId`）
- サーバは印を保存するが、**どの応答にも返さない**（返すと、同じ人のタワーをたどれてしまう）。一覧では「あなたのタワーか」だけを答え、その一覧は途中のキャッシュに残させない（`Cache-Control: private, no-store`）

## 3. サーバ（Cloud Run）

- **誰でも送れる URL なので、保存する前に検査する**：パーツは 10 個まで・点の数・座標の範囲・NaN・名前 30 字・作者名 20 字まで。読めない JSON は 400 で断る（`server/.../TowerValidation.kt`）。ニックネームの AI は 16 KB を超える送信を読まない
- **共有ページの文字はエスケープする**：作者名やパーツの名前を HTML に入れる前に `& < > "` をエスケープする（XSS 対策）。文の向きを入れ替える見えない文字（Unicode の書式文字）も取り除き、LINE や X のプレビューで文の順番を細工されないようにする（`SharePage.kt`）
- **AI の鍵を置かない**：Gemini は、Cloud Run のサービスアカウントで Vertex AI を呼ぶ。API キーは、アプリにもリポジトリにも無い。AI の返事は 1 行目だけを使い、文字数（パーツの名前は 10 文字まで）を検査してから返す。3 秒で打ち切る（決定 9）
- **料金が膨らむのを防ぐ**：Cloud Run は最大 2 台まで。予算アラートも設定してある
- 通信は https だけ（Cloud Run）

## 4. アプリ

- **本番は https だけ**：release ビルドは、暗号化しない通信（http）を許さない（`res/xml/network_security_config.xml`）。debug ビルドだけ、手元のサーバ（`http://10.0.2.2:8080`）用に http を許す
- **他人からもらったファイルを安全に読む**：GPX（XML）を読むときは、外部のファイルや DOCTYPE を読まない（XXE 対策。`core/io/TrackFileParser`）
- **地図のキーをリポジトリに置かない**：`local.properties`（git に入れない）と、CI は GitHub の Secrets から渡す。キーは「Maps SDK for Android だけ」と「このアプリの署名だけ」に制限してある

## 5. していないこと（理由）

| していないこと | 理由 | 本番にするなら |
|---|---|---|
| ログイン | 決定 23 で見送った（期間とデモの規模）。代わりに端末ごとの印（2、決定 32）で見分ける | Firebase Authentication の匿名ログインなど |
| 送る回数の制限 | 決定 23 で見送った（期間とデモの規模）。投稿と AI の API に付けることを、サーバ担当の C と相談中（Issue #3） | 端末の印か IP ごとに、1 分あたりの回数を決める |
| 改造したアプリからの送信を見分ける | 手間に比べて、デモでの危険が小さい | Play Integrity API・Firebase App Check |
| 非公開の署名の鍵 | チームの全員と CI が同じ署名にするため、鍵をリポジトリに置いている。APK はチームの外に配らない | Google Play の App Signing で、非公開の鍵にする |

## 6. 聞かれそうな質問

- **「道の形から、家の場所が分からない？」**
  緯度・経度は送らず、形も 24 点までに間引いている。ただ、北を上にした形と距離を地図と照らし合わせれば、手間をかければ当てられなくはない。そのため、「みんな」に送るかは自分で選ぶ（送らなければ、形もスマホの外に出ない）。本番なら、家の近くで始まった道は送る前に知らせる、といった手当てを考える
- **「AI に個人情報が渡らない？」**
  渡すのは形・距離・日時（名前付け）か、パーツの名前・本数・合計距離（ニックネーム）だけ。場所・自分で付けた名前・端末の印は送らない。設定でオフにもできる
- **「サーバに変なデータを送られたら？」**
  保存する前に形・数・文字数を検査して断る（3）。共有ページに出す文字はエスケープする

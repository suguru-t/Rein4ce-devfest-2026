# 模型の高さと歩いた距離（#43 前半）

積む画面の左に目盛用の列を設け、台の上面を0mとして1mの数字と20cmの補助目盛を表示する。補助目盛が8dp未満になると省略し、数字の間隔は文字の高さを考慮して1/2/5の系列で間引く。

塔と目盛は同じ `StackViewport`（補間中のzoomとcameraYを含む）を使う。余白を除いたキャンバスの幅で描画・ドラッグ・カメラを計算するため、余白の追加で指との対応は変わらない。#70で採用された「狙う間は追従、完成時は全体表示」を維持する。物理・保存・共有の高さは変更しない。

高さは「模型の高さ」、完成カードの歩行距離は「使った道：合計○km」と表示する。開始時に固定したセッションの全パーツ（落下したものも含む）から距離を集計して結果に固定する。

過去のパーツは実GPSとデモ再生のどちらも無印のUUIDだったため、確実な区別ができない。新規生成時のみIDを `walk-UUID`（実GPS）、`demo-UUID`（見本再生）、`file-UUID`（ファイル再生）に分ける。共有のPart形式や既存IDは変更しない。距離にはwalkだけを含め、見本・デモ・ファイル再生・過去の判別不能な記録は除外した個数を表示する。既存記録の出所を推測して書き換えない。

通常停止、再生の自動完了、速度超過による自動停止の全経路で、UIの再生ラベルとは別に記録開始時の出所を保持する（ラベル消去後に速度停止イベントが届いてもデモを実歩行にしない）。名称変更や削除は、既に開始したゲームの距離を変えない。

左右ボタンは#43後半の別PRで追加する。#45の手動B案はPR #78が対応中のため、このPRではそのブランチを変更しない。

# 左右ボタン（#43 後半）

置く前の操作段に◀▶を表示する。短押しで5cm、端末標準の長押し判定後は80msごとに5cmずつ動く。ドラッグと同じ `StackViewModel.dragBy` を使い、範囲の端で止まる。回転の刻み・物理・保存する座標は変更しない。

`combinedClickable` が通常のクリックと長押しを区別するため、長押しを離したときに余分なクリック移動はしない。Release/Cancel、操作不可への変更、画面離脱・背景化、セッション切替で反復を中止する。落下中・完成後はボタンを表示せず、VMのphase判定でも移動を拒否する。

既存の `pressFeel` とMaterialの枠・最小48dpの高さを使用する。読み上げは左右と5cmを伝え、アクセシビリティの長押し操作（物理的なReleaseを伴わないもの）は1回の移動にする。押したままになって動き続けない。

部品は `onMove` と `sessionKey` を受け取るので、#45のPR #78でも共用できる。このPRから進行中の #78 は書き換えない。#87の目盛・表記の上に積んだPRで、#87マージ後にbaseをmainへ変更する。

自動テスト：反復間隔と解除、反復の置き換え、ボタンとドラッグの交互操作、両端でのクランプ、落下中・終了後の操作拒否。実機での押し心地・長押し・TalkBackの確認は未実施。
